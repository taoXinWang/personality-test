# PersonalityTest Context

## Purpose

This glossary defines the canonical terms used in the PersonalityTest system. When these terms appear in code, documentation, or conversation, they carry the precise meanings defined here.

## Core Concepts

### Trait (特质)
A measurable dimension of personality that exists on a continuous spectrum (0-100%). Traits are stable characteristics that influence behavior across situations.

**Not**: Type, category, or discrete classification.

### Dimension (维度)
One of the five measurable traits in our system. Each dimension has two poles representing opposite ends of a spectrum.

The five dimensions are:
1. **Exploration (探索性)**: Openness to new experiences vs. preference for familiarity
2. **Structure (规划性)**: Preference for planning and organization vs. spontaneity
3. **Social Energy (社交性)**: Orientation toward social interaction vs. solitude
4. **Harmony (协作性)**: Tendency toward cooperation vs. competition
5. **Resilience (心理韧性)**: Emotional stability vs. sensitivity (调节维度)

### Archetype (性格原型)
One of 16 distinct personality patterns generated by the combination of four dimensions (Exploration, Structure, Social Energy, Harmony). Each archetype has:
- A 4-letter code (e.g., ICOH)
- A Chinese name (e.g., 创新协调者)
- An English name (e.g., The Visionary Harmonizer)

**Not**: The result of all five dimensions. Resilience acts as a modifier, not a type generator.

### Pole (极)
One end of a dimension's spectrum. Each dimension has two poles:

**Exploration**: Innovator (创新者, high) ↔ Pragmatist (务实者, low)
**Structure**: Planner (计划者, high) ↔ Spontaneous (自由人, low)
**Social Energy**: Outgoing (外向者, high) ↔ Reserved (内敛者, low)
**Harmony**: Harmonizer (协调者, high) ↔ Challenger (挑战者, low)

### Preference Strength (偏好强度)
The degree to which a user leans toward one pole of a dimension. Measured as distance from the 50% midpoint:
- **Strong preference (强烈偏好)**: >70% or <30%
- **Moderate preference (中等偏好)**: 55-70% or 30-45%
- **Slight preference (轻微偏好)**: 45-55%

**Why**: Users near the boundary (45-55%) should understand their classification is less definitive.

### Type Modifier (类型调节符)
The Resilience dimension result, expressed as a suffix:
- **-S (Stable, 稳定型)**: Resilience ≥50%
- **-T (Turbulent, 敏感型)**: Resilience <50%

Modifiers refine an archetype (e.g., ICOH-S vs ICOH-T) but do not create new archetypes.

### Question (题目)
A single test item presented to the user. Each question:
- Belongs to exactly one dimension
- Has a scoring direction (forward or reverse)
- Uses a 7-point Likert scale (1 = strongly disagree, 7 = strongly agree)

### Forward Question (正向题)
A question where agreement indicates the high pole of a dimension.

Example (Exploration): "我喜欢尝试新鲜事物" — agreeing → high Exploration score.

### Reverse Question (反向题)
A question where agreement indicates the low pole of a dimension. The score is inverted during calculation.

Example (Exploration): "我更喜欢按照熟悉的方式做事" — agreeing → low Exploration score (inverted to 1-2 range).

**Why**: Prevents response bias where users habitually select the same side of the scale.

### Result Profile (结果档案)
The complete output shown to a user after completing the test:
- Archetype label (code + name)
- Five dimension scores with preference strengths
- Detailed archetype description
- Three scenario applications (workplace, romance, social)

### Scenario Application (场景应用)
Practical guidance for how an archetype manifests in a specific life domain:
- **Workplace (职场)**: Career strengths, work style, team dynamics
- **Romance (恋爱)**: Relationship patterns, communication style, compatibility
- **Social (社交)**: Friendship approach, social preferences, conflict handling

### Anonymous Data (匿名数据)
Test responses and results collected without personally identifiable information. Used for:
- Improving question quality
- Generating population statistics
- Validating the measurement model

**Not**: Linked to user accounts unless the user explicitly registers.

### Shareable Result Link (可分享结果链接)
A unique URL (e.g., `/result/abc123`) that displays a user's archetype and dimension scores. Anyone with the link can view the basic result.

## Boundaries

### What is NOT in scope for V1

- **Celebrity examples**: No "famous people with your type" feature
- **Cultural adaptation**: Questions are translated but not culturally localized
- **Paid features**: No premium reports or subscriptions
- **Team/enterprise features**: No group testing or organizational dashboards
- **Additional languages**: Only Chinese and English

### Archetype vs. Dimension Score

An **archetype** is a categorical label derived from four dimensions. A **dimension score** is a continuous percentage (0-100%). Users receive both: the archetype for identity and shareability, the scores for nuance and self-understanding.

### Registration vs. Anonymous Testing

Users can complete the test without an account (**anonymous testing**). After seeing results, they can optionally register to save their profile and access it later (**optional registration**). Registration is never required to take the test or view results.

## Calculation Rules

### Dimension Score Calculation
For each dimension with 10 questions:
1. Sum raw scores (1-7 per question)
2. Reverse-score the 4 reverse questions: `reversed_score = 8 - raw_score`
3. Total possible: 70 points (10 questions × 7 max)
4. Percentage: `(total_score / 70) × 100`

### Archetype Assignment
For each of the four type-generating dimensions (Exploration, Structure, Social Energy, Harmony):
- If score ≥50%: assign high pole letter
- If score <50%: assign low pole letter

Combine the four letters to form the archetype code.

### Type Modifier Assignment
For the Resilience dimension:
- If score ≥50%: assign -S (Stable)
- If score <50%: assign -T (Turbulent)

Append to the archetype code (e.g., ICOH-S).
